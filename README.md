# Aar Ya Paar

This repository contains two separate projects:

- `frontend/` — the Expo / React Native app
- `backend/` — the Python API

## Run the mobile app

Run Expo from the frontend directory, where its `package.json` lives:

```powershell
cd frontend
npm install
npx expo start
```

Or, from the repository root:

```powershell
npm --prefix frontend install
npm --prefix frontend exec expo start
```
